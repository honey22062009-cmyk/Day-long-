# Day Long

A Godot 4 starter project intended for Android tablets and mobile devices.

## Open in Godot

1. Download or clone this repository onto your device.
2. Open Godot Editor.
3. Choose **Import** and select the folder containing `project.godot`.
4. Open the project and press **Run**.

## Current status

- Godot project configuration added.
- Minimal main scene and scripted starter screen added.
- Android export configuration and game-specific features are not set up yet.

The game concept and mechanics will be added after they are defined.
