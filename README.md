# Day Long Addict

A single-player 3D open-world survival game for Android, built with Unity.

## Project status

**Repository initialized.** This repository currently contains only starter documentation and Git ignore rules. Game systems and Unity scenes have not been created yet.

## Planned technology

- Unity 6 (or Unity 2022 LTS)
- C#
- Universal Render Pipeline (URP)
- New Input System
- TextMeshPro
- Android as the target platform

## Planned development phases

1. Project setup, touch controls, third-person character, and camera
2. Procedural chunk-streamed terrain and biomes
3. Inventory
4. Gathering and mining
5. Crafting and equipment upgrades
6. Building
7. Timed task system
8. Wildlife AI
9. Day/night cycle, weather, and graphics polish
10. Saving, menus, optimization, and Android build

## Getting started

Create the Unity project in the Unity Hub, then place its files in this repository. Use the Unity version selected for the project consistently.

Do not commit generated folders such as Library/, Temp/, Obj/, or build output. See the .gitignore file.

## Target

Android phones. Performance will be measured on device, with a 60 FPS goal on capable hardware and a 30 FPS fallback.
